## Structure
```
/
├── index.html              ← portfolio homepage
├── assets/
│   ├── css/style.css
│   ├── js/script.js
│   ├── images/             ← profile.webp, og-image.jpg, projects/ thumbnails
│   └── Muzahidul_Islam_CV.pdf
├── <project-folders>/      ← each project is a self-contained mini-site
├── _templates/             ← card + starter for new projects (not published)
├── robots.txt
├── sitemap.xml
└── UPDATE-GUIDE.md         ← how to maintain this portfolio
```

## Deployment
GitHub Pages, deployed from the repository root. Keep `index.html` and all project folders at the root.
