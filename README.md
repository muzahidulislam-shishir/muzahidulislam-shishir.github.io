## Run Locally

Open `index.html` in a browser. Internet access is needed for Bootstrap, icons and Google Fonts.

For the best development experience, use the VS Code **Live Server** extension.

## Deploy with GitHub Pages

1. Create a public GitHub repository named `my-portfolio`.
2. Push the contents of this folder so `index.html` is in the repository root.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save and wait for GitHub Pages to publish the site.
